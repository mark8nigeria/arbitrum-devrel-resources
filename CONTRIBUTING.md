# Contributing to Arbitrum DevRel Resources

Thanks for your interest in contributing 👋  
This repository is designed to be **beginner-friendly and community-driven**.

---

## 🧠 What You Can Contribute
You don’t need to be an expert to contribute.

We welcome:
- Documentation improvements
- Beginner-friendly explanations
- Workshop notes
- Resource links
- Code examples
- Fixing typos or clarity issues

Docs contributions are just as valuable as code.

---

## 🛠️ How to Contribute
1. Fork this repository
2. Create a new branch
3. Make your changes
4. Submit a Pull Request (PR)
5. Clearly explain what you added or improved

That’s it.

---

## 🧩 Contribution Guidelines
- Keep language simple and clear
- Assume the reader is learning
- Avoid unnecessary jargon
- Be respectful and collaborative

This is a learning-first repository.

---

## 🟢 Good First Issues
If you’re new to open source:
- Look for issues labeled `good first issue`
- Ask questions if anything is unclear
- Small contributions are encouraged

---

## 🤝 Code of Conduct
Be kind. Be helpful. Be professional.

This repository exists to support developers and grow the community.
