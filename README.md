# Arbitrum DevRel Resources 🚀

A growing collection of **developer-focused resources, guides, and learning materials** curated and maintained by **PlutoDev**.

This repository is built for developers who want clear, practical support while building and learning within the Arbitrum ecosystem.

---

## 🎯 Purpose
Developer Relations is not just content — it’s clarity, support, and momentum.

This repo exists to:
- Help developers learn faster
- Reduce friction during onboarding
- Provide practical, reusable resources
- Support workshops, talks, and community programs

---

## 👥 Who This Is For
- Developers new to Arbitrum
- Students and campus communities
- Hackathon participants
- Builders looking for practical examples
- DevRel practitioners and educators
