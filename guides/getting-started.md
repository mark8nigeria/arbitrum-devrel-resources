# Getting Started with Arbitrum (Builder-Friendly Guide)

This guide is for developers who want a **clear, no-noise entry point** into building on Arbitrum.

No assumptions. No buzzwords. Just the basics you need to get moving.

---

## 🧠 What is Arbitrum?
Arbitrum is a Layer 2 scaling solution built to make Ethereum faster and cheaper, while keeping Ethereum-level security.

For developers, this means:
- Lower gas fees
- Faster transactions
- Familiar Ethereum tooling

If you’ve built on Ethereum before, Arbitrum will feel familiar.

---

## 👥 Who This Guide Is For
- Developers new to Arbitrum
- Students learning blockchain development
- Hackathon participants
- Builders coming from Ethereum

---

## 🧰 Prerequisites
Before you start, you should have:
- Basic JavaScript knowledge
- Some familiarity with Ethereum concepts
- Node.js installed
- A GitHub account

That’s enough to begin.

---

## ⚙️ Development Environment
Most Ethereum tools work seamlessly on Arbitrum.

Commonly used tools:
- Hardhat
- Foundry
- Remix
- MetaMask

You don’t need new tools — just the right configuration.

On Arbitrum, developers commonly build:
